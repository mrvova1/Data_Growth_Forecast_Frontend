# Лабораторная работа №5 — React SPA

**Тема:** «Прогноз роста объёма данных»
**Стек:** React 19, TypeScript, Vite, React-Bootstrap, React Router.
**Режим:** гостевой интерфейс; данные карточек загружаются только из локальной mock-коллекции. Backend для запуска и работы ЛР5 не требуется.

## 1. Запуск

Требуется Node.js 20.19+ или 22.x и npm.

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000`.

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## 2. Маршруты и экраны

В приложении три маршрута/режима отображения: лента, просмотр выбранной услуги в ленте и плитка. В нижней панели доступны только «Лента» и «Плитка».

### 2.1. Лента — `/feed`

Гостевая лента показывает по одной услуге за раз в вертикальном медиа-блоке, который занимает свободную высоту между шапкой и нижней навигацией. На странице ленты вертикальная прокрутка отключена.

Элементы:

- видео с изображением-постером;
- тема, название, краткое описание и число лайков;
- кнопка «Читать далее» / «Скрыть»;
- показатели «Рост» и «Влияние»;
- кнопка «Далее» справа внутри видеоблока — переход к следующей записи mock-коллекции с циклическим возвратом к первой.

При отсутствии `video_url` используется локальный `public/assets/default-service-video.mp4`; при отсутствии `image_url` используется `public/assets/default-service-image.png`. При ошибке загрузки видео выполняется переход на локальное видео по умолчанию, а если оно также недоступно — показывается изображение-заглушка.

### 2.2. Просмотр выбранной услуги — `/feed/:id`

Кнопка «Далее» перемещает на следующую услугу в порядке mock-массива и обновляет URL на `/feed/{следующий_id}`. Пункт «Лента» нижней навигации возвращает на `/feed`.

### 2.3. Плитка — `/tile`

Страница выводит услуги в две колонки. Над списком находится форма фильтрации.

Поля и кнопки:

- **Тема** — обязательный фильтр по mock-полю `category`;
- **Рост от** — дополнительный фильтр по минимальному значению `growth_coefficient`;
- **Сбросить** — очистить фильтры.

## 3. Нижняя навигация

Панель расположена снизу и содержит четыре пункта:

| Пункт | Состояние | Назначение |
|---|---|---|
| Лента | доступен | переход на `/feed` |
| Добавление | отключён | добавление услуги недоступно гостю в ЛР5 |
| Плитка | доступен | переход на `/tile` |
| Вход | отключён | авторизация не реализуется в гостевом режиме |

На маршруте `/feed/:id` активным остаётся пункт «Лента».

## 4. Mock-данные и Network

Коллекция находится в `public/mock/services.json`. При запуске `useServices` выполняется запрос:

```http
GET /mock/services.json
```


## 5. Изображение и видео по умолчанию

Файлы находятся в `public/assets/`:

- `default-service-image.png` — локальное изображение-заглушка;
- `default-service-video.mp4` — локальное видео-заглушка.

Логика путей централизована в `src/utils/media.ts`:

- пустая строка, `null` или `undefined` в `image_url` заменяется на `DEFAULT_IMAGE`;
- пустая строка, `null` или `undefined` в `video_url` заменяется на `DEFAULT_VIDEO`;
- если изображение услуги не загружается, `onError` назначает локальную картинку;
- если видео не воспроизводится, сначала используется видео по умолчанию; если недоступно и оно, показывается локальное изображение.

В mock-коллекции специально оставлены записи с пустыми или `null`-значениями медиа, чтобы продемонстрировать fallback.

## 6. Компоненты, props и хуки

### Компоненты и передаваемые props

| Компонент | Props | Назначение |
|---|---|---|
| `AppLayout` | `children: ReactNode` | общая оболочка, шапка и нижняя навигация |
| `FeedPage` | `services`, `loading`, `error`, `onRetry` | лента и просмотр выбранной услуги по ID |
| `TilePage` | `services`, `loading`, `error` | фильтрация и отображение плитки |
| `ServiceCard` | `service: Service` | карточка и ссылка `/feed/{id}` |
| `ServiceFilters` | `category`, `minGrowth`, `categories`, callback-функции | контролируемая форма фильтрации |
| `BottomNav` | нет | нижняя навигация |

**Передача props фильтров:** `TilePage` хранит тему и минимальный коэффициент роста через `useState`, а затем передаёт их в `ServiceFilters` вместе с `setCategory`, `setMinGrowth` и `resetFilters`. Дочерний компонент не меняет состояние родителя напрямую, а вызывает переданные callback-функции. `TilePage` пересчитывает список через `useMemo`.

**Передача props карточки:** `TilePage` передаёт объект `service` в `ServiceCard`. Карточка отображает его поля, а URL перехода формирует по `service.id`.

### Используемые React и Router hooks

- `useState` — состояние mock-данных, загрузки и ошибки в `useServices`; индекс ленты, раскрытие описания и состояние fallback-видео в `FeedPage`; значения фильтров в `TilePage`.
- `useEffect` — загрузка `services.json` после монтирования с отменой запроса через `AbortController`; сброс состояния раскрытия и видео при смене выбранной услуги.
- `useCallback` — мемоизация функции загрузки mock-данных и обработчика перехода к следующей услуге.
- `useMemo` — вычисление списка тем и отфильтрованного массива услуг.
- `useLocation` — определение активного пункта нижней навигации и режима прокрутки оболочки.
- `useNavigate` — переход к следующей услуге и возврат на плитку при некорректном ID.
- `useParams` — получение ID из маршрута `/feed/:id`.

`useContext`, Context API и Redux не используются. Данные передаются через обычные props.

## 7. Контрольные вопросы

**1. Что такое React?**
React — JavaScript-библиотека для декларативного построения пользовательских интерфейсов из компонентов. Разработчик описывает состояние и желаемую разметку, а React обновляет DOM при изменении данных.

**2. Что такое props и state?**
Props — входные данные компонента, которые передаёт родитель; дочерний компонент рассматривает их как доступные только для чтения. State — внутреннее изменяемое состояние компонента. Изменение state через setter вызывает повторный рендер.

**3. Чем компонент отличается от элемента?**
Компонент — функция или класс, описывающие повторно используемую часть интерфейса. React-элемент — описание конкретного узла интерфейса, которое React использует при построении дерева отображения.

**4. Для чего нужны `useState` и `useEffect`?**
`useState` хранит локальное состояние и возвращает текущее значение с функцией обновления. `useEffect` запускает побочные действия после рендера: загрузку данных, подписки и синхронизацию с внешними системами. Функция возврата из эффекта очищает ресурс.

**5. Что такое жизненный цикл компонента?**
Основные этапы: монтирование (первое появление), обновление (повторный рендер при изменении props/state) и размонтирование (удаление из дерева). В функциональных компонентах побочные действия и очистка обычно оформляются через `useEffect`.

**6. Что такое Vite и Babel?**
Vite предоставляет dev-сервер, быструю перезагрузку модулей и production-сборку. В проекте используется React-плагин Vite для обработки JSX и Fast Refresh. Babel — инструмент преобразования JavaScript/JSX и подключаемых языковых возможностей; он не заменяет проверку типов TypeScript. В `npm run build` проверка типов выполняется командой `tsc`.
